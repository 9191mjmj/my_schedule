# 📅 我的课表桌面版

一个基于 Electron 的课表桌面应用，专为中国地质大学（武汉）学生设计。  
支持**一键登录信息门户、自动抓取教务系统课表、按周查看**，无需手动复制 Cookie。

---

## ✨ 功能特性

- 📥 **一键导入课表**  
  点击"导入课表"按钮，App 内置浏览器会打开学校统一身份认证页面。  
  登录成功后自动跳转教务系统，抓取你的真实课表。

- 🗓 **按周次筛选**  
  顶部下拉框选择周次，或点左右箭头，自动高亮本周。

- 📊 **今日概览卡片**  
  显示下一节课、本周课程数、今日课程数、当前北京时间。

- ⏰ **实时时钟**  
  左上角和右上角的时间每秒刷新，始终显示准确北京时间。

- ⚙️ **自定义上课时间**  
  不同学校、不同季节作息不同，可自行修改每一大节的时间。

- 🖼 **自定义背景图**  
  上传本地图片作为课表背景，数据存在浏览器本地。

- 🌗 **深色 / 浅色主题**  
  右上角太阳/月亮图标一键切换，保护眼睛。

- 🔒 **安全登录**  
  学号和密码不会保存在本地，登录状态由学校系统管理。

---

## 🛠 技术栈

| 技术 | 用途 |
|------|------|
| Electron | 桌面应用外壳 |
| Node.js + axios | 主进程抓取教务系统数据 |
| Webview | 内嵌浏览器完成登录 |
| 原生 HTML / CSS / JavaScript | 前端界面 |
